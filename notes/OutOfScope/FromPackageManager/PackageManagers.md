### Distribution-Specific Managers
*   **APT:** For Debian, Ubuntu, and Mint.
*   **DNF:** For Fedora, RHEL, and Rocky.
*   **Pacman:** For Arch Linux and Manjaro.
*   **Zypper:** For openSUSE systems.
*   **Portage:** For Gentoo source compilation.
*   **APK:** For lightweight Alpine Linux.
*   **XBPS:** For Void Linux.

### Universal Formats
*   **Flatpak:** Sandboxed desktop GUI apps.
*   **Snap:** Canonical's cross-distro package format.
*   **AppImage:** Portable, single-file executable apps.

### Functional Managers
*   **Nix:** Reproducible, isolated environment builds.
*   **Guix:** GNU functional package management.

### Low-Level Frontends
*   **Dpkg:** Base tool for Debian.
*   **RPM:** Base tool for Red Hat.
